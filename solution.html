Electronic anti-theft system for motorcycle

SMC RFID electronic key is the extension of the application of RFID technology products, the lock signal is sensed when the electronic key is turned ON, and will start the motorcycle when the signal is correct. If a thief use a non-signal matching key to steal, it can not be launched because there is no a sensor chip in the key, so that can effectively achieve anti-theft effect.
