SMC995326-44DBS

產品編號：995326-44DBS

SMC995326-34/44Dxx 是一個 3/4 態 4 DATA 免割碼的編碼器 IC,有多種型號提供各種不同應 用之需要.以 CMOS 製程製造,耗電極小,接收端必須配合一顆 MCU IC 來解碼,內含 12 BIT 的位 址碼及資料碼,將此位址碼及資料碼編碼之後,以串列的方式經 DOUT 輸出,輸入資料碼最多有 4 個資料位元及最多有 12 個位址位元,而資料位元 (DATA BIT) 的應用可以從 1 Data BIT～4 Data BIT 可供選擇,位址位元 (ADDRESS BIT) 編碼的方式在 IC 生產的時候以電腦完成自動編碼,所以每一個 IC 在生產完成之後,已經有一個固定而且是不可變更的 ADDRESS BIT ,也就是 SECURITY CODE 。

特點：

  • 1.工作電壓: 2.3V～13.5.0V 。
  • 2.SMC995326-34DXX 是一個 3態 4 DATA 免割碼的編碼器 IC。
  • 3.SMC995326-44DXX 是一個 4態4 DATA 免割碼的編碼器 IC
  • 4.靜態電流: 消耗功率非常低 (stand-by 約1 ~ 3μA , Operating約600μA)。
  • 5.IC 振盪頻率非常穩定,在外加同樣阻值的情況下, 每一個 IC 的振盪頻率,甚至每一批 IC 的振盪頻率,誤差在 ±3 % ～ ±5 % 以內。
  • 6.P.C.B layout 簡單容易,使用單層 P.C.B 板即可,降低整體產品成本。
  • 7.每一個 IC 出廠前已經將 SECURITY CODE 編碼完成,生產線上免割碼。
  • 8.全系列的編碼 IC ,可提供廠商更多樣的應用。
  • 9.特殊功能的免割碼編碼 IC ,可以減少外部零件。
  • 10.SMC995326-34Dxx 系列完全相容於 AX5326-3 可以直接取代使用。
  • 11.SMC995326-44Dxx 系列完全相容於 AX5326-4 可以直接取代使用。
  • 12.SMC995326-34Dxx 特殊設計使 16 PIN IC 可提供四個 DATA PORT。
  • 13.SMC995326-44Dxx 特殊設計使 16 PIN IC 可提供四個 DATA PORT。
  • 14.當 SMC995326-3 (3態) 密碼組數不足時可直接升級使用 SMC995326-4 (4態) 不必更換 P.C.B. 直接更換 IC 即可,可節省廠商的庫存及備料問題。
