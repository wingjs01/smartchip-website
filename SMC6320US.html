SMC6320US

Product Number: 6320US

The SMC6320US is a Bluetooth-enabled NFC smart reader/writer that reads tags compliant with the ISO14443A and ISO15693 protocols. Combining 13.56 MHz and Bluetooth 4.2, it works connected to a PC or online, making it ideal for IoT deployments.

The SMC6320US communicates over BLE 4.2 with iOS and Android devices. When connected, it automatically labels each tag as ISO14443A or ISO15693 according to the tag type. Reading modes include command mode (read/write), single-read mode and continuous-read mode, and anti-duplicate reading is enabled automatically when a card is read.

Its read/write function works with most NFC tags and devices, for applications such as automated access-control verification, inventory management and logical access control.

Basic Functions:

  • 1. Communication Protocol: ISO14443A + ISO15693.
  • 2. Supported systems: PC, iOS and Android (on iOS, Bluetooth must be connected manually).
  • 3. Single-read mode does not store data; it is only used to read card numbers.
  • 4. In continuous-read mode, IDs are stored in the app automatically.
  • 5. App functions:
    • a. The following settings must be made while connected via Bluetooth.
    • b. Protocol: choose 14443A, 15693 or a combination.
    • c. Card reading mode:
      • In continuous-read mode, the tag UID is read continuously each time the key is pressed.
      • In single-read mode, the tag UID is read once per key press (place the card first, then press the button).
    • Anti-duplicate reading: each ID is compared with the previous 6 IDs; duplicates are not stored and are highlighted in color.
  • 6. Connect to a PC via USB to read/write tags.
  • 7. 4 LEDs and a beeper indicate operating status.
  • 8. Built-in 500 mAh rechargeable battery.
  • 9. PC and app software provided.
  • 10. API protocol provided for secondary development.
