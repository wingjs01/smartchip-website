SMC632AS/ 632AUS Note: We accept customized service of this product. The working frequency, interface, communication protocol and operation mode can be changed according to customer requirements.

Product Number：632AS/ 632AUS

The SMC632ES series is a 13.56 MHz single-antenna ISO14443A & ISO15693 non-contact inductive reader module. The module uses SMC632 chip design (SMC632 is RF Frontend & Control Interface 2-in-1 decoding control chip), which is a reader module designed to read SMC4111 UID and R/W ISO14443A & ISO15693 standard communication protocols.

Users do not need to know any complicated control commands of RF chips such as RC22/RC500/RC400/RC632, and do not need to understand some problems such as the complex key and access control of MIFARE card. To understand the instructions of this product, you only need to use the simple three commands (read data, write data and modify the key), then you can fully grasp the data read/write operation of the MIFARE in the shortest time. Also, this module is easy to understand and easy to use, and the anti-collision processing module has been automatically solved for you, so that beginners can complete development design quickly, shorten development time, reduce development costs, and reduce overall product cost. This module series provides UART interface can communicate directly with the MCU motherboard.
