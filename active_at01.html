Active RFID

Product Number: SMC-AT01

The SMC-AT01 is an active RFID tag developed for a wide range of applications. It offers powerful features and multiple optional interfaces, with very low power consumption: 6 µA on average and less than 1 µA in sleep mode.

Technical Specifications

Specification Description
Operating Frequency 2.4–2.4835 GHz (16 selectable channels)
Data transfer rate 64, 125 or 250 kbps (selectable)
Reading distance Max. 100 m (open space)
Read rate Up to 100 tags per second
Transmit Power 1 to -30 dBm (adjustable)
Working temperature Max. 75 ℃, min. -30 ℃
Battery Lithium manganese (CR2032, CR3032)
Battery life 1–6 years (battery life is shorter at extreme temperatures)
Identifier 64 bit
Data encryption 16-bit dynamic bidirectional encryption algorithm
Memory capacity 96 bytes (real-time read/write)
LED Red LED × 1
Battery monitoring Low voltage warning
Tag sleep interval 1, 1.5, 2 or 3 s (selectable)
Automatic ID broadcast interval Every 1–36,000 s (adjustable)
Tag search function Supports tag search (LED flashing)
Average power consumption < 6.0 ua
Sleep power consumption < 1.0 ua
Certification Standards FCC Part 15
