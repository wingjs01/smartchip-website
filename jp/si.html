SI · System Integration

センサーからクラウドまで、ひとつのチームで

SMCはチップを設計し、モジュールやキオスクを製造し、エッジAIハードウェアを提供し、ソフトウェアも開発します。それらを動くシステムとしてまとめ、稼働後もサポートします。現在、台湾最大の小売システムにサービスを提供しています。

システムの構成

SMCのシステムは一般的に4つの層で構成されます。

センシングRFID／NFC、BLE、2.4 GHzアクティブタグ、カメラ
エッジPandoraエッジ AIコンピューター、産業用PC
インタラクションセルフサービスキオスク、ディスプレイ、アプリ
バックエンドクラウドサービス、データベース、ダッシュボード

システム事例

Retail / logistics

スマート荷物受取

台湾最大の小売システムで稼働中。受付精算キオスクとロッカー管理に、行列や安全監視用のAIカメラを組み合わせます。

Access

入退室・勤怠管理

RFID／NFCリーダー、モバイルウォレットのパス、キオスクを人事・来訪者システムと連携します。

Assets

資産・人員の位置管理

固定式とハンディ型のリーダーを使った2.4 GHzアクティブRFIDと位置ダッシュボード。

Showcase

展示会・デモシステム

Pandoraエッジ AI、キオスク、RFIDを組み合わせた展示会向けのインタラクティブデモ。

事例：通い箱の UHF RFID 出荷・回収管理

Android の UHF RFID ハンディ端末で、通い箱を梱包から納品、回収まで一箱ずつ追跡する独立システムです。箱の管理に特化しているため、ERP と連携せずに短期間で導入できます。

Shipping

誤出荷を防止

積み込み時に箱を一括スキャンし、出荷指示と照合します。不足や余分な箱はその場で表示され、差異がある場合は責任者の承認が必要です。

Delivery

納品の証跡

納品先で再スキャンし、顧客が端末に手書きでサイン。写真を時刻と GPS 付きで保存します。

Returns

空箱の回収

回収した箱をスキャンして受領サインを取得。その顧客に登録された箱のみ受け付け、工場で入庫処理します。

Alerts

顧客先の在箱数

顧客ごとの在箱数をリアルタイムに集計し、設定日数を超えた箱を警告表示します。

通い箱のライフサイクル

各箱について、状態、場所、担当者、最終スキャン時刻と端末、内容物、バーコード、受領サイン、返却サインを記録します。

Handheld app

UHF RFID ハンディ端末

箱の一括スキャン、1D バーコードによる予備読取、サインと写真の記録、電波のない場所でも使えるオフライン送信待ち。

Back end

API サーバー

出荷指示とスキャン結果の照合、箱の状態管理、責任者の PIN／遠隔承認、超過アラート、ユーザー権限。

Console

データベースと Web 管理画面

箱の検索、在外箱レポート、異常処理、電子納品書。
