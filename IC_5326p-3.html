SMC5326P-3W

Product Number: 5326P-3W

The SMC5326P-3W is a tri-state cut-code encoder IC with 12 address and data bits. After encoding, it outputs the address and data bits serially through DOUT. Multiple variants are available for different applications. It is made in a high-voltage CMOS process with extremely low power consumption; the receiver must use the SMC65327 or SMC5327 for decoding.

The SMC5326P-3W has 12 address-bit input pins, each of which can be set to 0, 1 or OPEN (tri-state). Because the SMC5326 defaults the address and data bits to 3 (tri-state), unconnected (OPEN) pins are automatically encoded as 3. When all 12 address pins are used for encoding, 531,441 code combinations are available.

Features:

  • 1. CMOS process.
  • 2. Low power consumption.
  • 3. High noise immunity.
  • 4. Up to 12 bits for encoding.
  • 5. Up to 4 bits when used for key input.
  • 6. Operating voltage: VDD = 3–15 V.
  • 7. A single resistor sets the oscillator.
  • 8. SMC65327 and SMC5327 offer latched or momentary output modes.
  • 9. Available in DIP and SOP packages.
  • 10. When TE is triggered from HIGH to LOW, DOUT sends 16 data frames.

Applications:

  • 1. Home security / automation systems
