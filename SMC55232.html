SMC55232 Bluetooth Module

Product number：SMC55232

Use app to control the motor, can be customized design。

With communication and transmission data encryption and decryption.

(N segments of arbitrary intercepted packets cannot be operated on.) The password is 16 bytes in length, and the data range per byte is 0x00 ~ 0xFF. With 4 keys, 1 main key and 4 sub keys, 4Key special function extension key, including 1 hidden key.

Each sub-Key has a name and creation date, and it needs to be logged in when operating the system.

With RTC function, when the battery is dead or when the battery is replaced or reset, the time will be automatically corrected every time you connect.

The main key can create sub-keys according to the user's preference and authorize others to use them.

With Log tracking events (2048 records), any actions of login and logout operations are recorded.

With a broadcast band voltage detection 30s update.

Automatically close the lock 3 seconds after unlocking. This function is turned off by default and needs to be turned on through the App.

The above functions can be customized design, adding or removing functions.
