SMC5238

Product Number：SMC5238

The SMC5238 series is a 13.56MHz non-contact inductive reader module which combinedISO14443A/B ISO15693 standard communication protocol. This module is designed to read SMC4111 UID and read/write ISO14443A & ISO15693 standard communication protocol reader modules. Users do not need to understand any complex control commands of RF chips such as RC522/RC500/RC400/RC632, nor do they need to understand complex issues such as Mifare card keys and access control.By understanding the instructions for using this product, users only need to use the simplest 3 commands (read data, write data, and modify keys) to fully master the read/write operation of Mifare cards in the shortest time. It's easy to understand and easy to use, with collision handling modules automatically taken care of, allowing beginners to quickly complete development design tasks, shorten development time, reduce development costs, and effectively reduce overall product costs. This module series provides UART, USB, and RS232 interfaces for direct communication with MCU motherboards and computers/phones.

Certification: FCC, CE, NCC
