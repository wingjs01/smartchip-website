Dual-Band BLE Reader

Product Number: SMC-P135134S

The SMC-P135134S is a BLE-enabled NFC smart reader/writer that reads tags compliant with the ISO14443A, ISO15693 and ISO11784/5 protocols. Combining 13.56 MHz, 134 kHz and BLE 4.0, it works both online and offline, making it ideal for IoT deployments.

The SMC-P135134S communicates over BLE 4.0 with iOS and Android devices and also works offline. It automatically stores up to 1,000 IDs whether connected or offline, and labels each ID as ISO14443A, ISO15693 or ISO11784/5 according to the tag type. Reading modes include command mode (read/write), single-read mode and continuous-read mode, and anti-duplicate reading is enabled automatically when a card is read.

Its read/write function works with most NFC tags and devices, for applications such as access control, inventory management and automated logical access verification.

Basic Functions:

  • 1. Protocol: ISO14443A + ISO15693 + ISO11784/5.
  • 2. Supported systems: PC, iOS and Android.
  • 3. Single-read mode does not store data; it is only used to view card numbers.
  • 4. Stores up to 1,000 IDs. The selected mode (continuous or single read) is remembered whether connected or offline.
  • 5. Control priority: USB > App = Mode key.
  • 6. Command mode is available only in the PC software; tags can be read and written when connected.
  • 7. 4 LEDs and a beeper indicate operating status.
  • 8. Built-in 500 mAh rechargeable battery.
  • 9. Standby time after a full charge is about 10 months or more; continuous use time is about 1 month.
  • 10. Supports more than 500,000 reads per day.
  • 11. PC and app software provided.
  • 12. API protocol provided for secondary development.
  • 13. APP functions:
    • a. The following settings must be made while connected via BLE.
    • b. Protocol: choose 14443A, 15693, ISO11784/5 or a combination.
    • c. Reading mode:
      • Continuous-read mode: tap the continuous-read button to read cards continuously.
      • Single-read mode: tap the single-read button to read a card once.
    • d. Anti-duplicate reading: each ID is compared with the previous 6 IDs; duplicates are not stored and are highlighted in color.
